Настройки программы

Меню настроек открывается, если запустить программу с удерживаемым Shift. Учётные данные вводятся один раз, сохраняются в зашифрованном виде и больше не отображаются.

1. Сервер 1С:Предприятие (RAS)

Адрес сервера администрирования кластера. Обычно это сам сервер 1С и порт 1545.

2. Администратор Windows-сервера

Учётные данные вводятся один раз и используются, чтобы посмотреть службы 1С и при необходимости запустить сервер администрирования (RAS), если он остановлен.

3. Правило очистки сеансов

Как программа решает, какой сеанс считать «максимально актуальным».

5. Службы 1С на Windows-сервере

Если сервер администрирования (RAS) остановлен, сеансы получить нельзя. Здесь службу можно запустить, не выходя из программы.
