ЧТО ДЕЛАЕТ ПРОГРАММА
Программа подключается к серверу администрирования 1С (RAS, порт 1545),
показывает все активные сеансы и по кнопке «Удалить старые» завершает
устаревшие дубликаты: по каждому пользователю в каждой информационной базе
остаётся только самый актуальный сеанс. Служебные сеансы (регламентные
задания, консоль сервера, веб-сервер и т.п.) не завершаются никогда.

ПЕРВЫЙ ЗАПУСК
1. Запустите ярлык «Очистка сеансов 1С» — программа запросит права
   администратора (это нормально и необходимо).
2. Программа откроется сразу на экране настроек: укажите сервер 1С
   (имя или IP, порт 1545), администратора кластера и, при необходимости,
   администратора Windows-сервера.
3. Нажмите «Сохранить настройки». Учётные данные будут зашифрованы
   (DPAPI + AES-256-GCM) в %ProgramData%\1C Session Cleaner\settings.dat
   и больше нигде не отображаются — посмотреть их нельзя, только заменить.

ДАЛЬНЕЙШАЯ РАБОТА
- Обычный запуск по ярлыку открывает главный экран со списком сеансов.
- Кнопка «Показать сеансы» — получить свежий список с сервера 1С.
- Кнопка «Удалить старые» — показать план и после подтверждения завершить
  устаревшие сеансы. Пользователь увидит пояснение из настроек.
- Меню настроек открывается ТОЛЬКО если запустить программу с удерживаемым
  Shift (или ярлыком «Настройки» в меню «Пуск»). Это защита от случайной
  правки учётных данных.

ОЧИСТКА ПО РАСПИСАНИЮ
Если при установке была выбрана секция «Автоочистка по расписанию»,
планировщик Windows ежедневно в 02:00 запускает:
    SessionCleaner.exe -clean -yes
без окна; результат пишется в журнал программы.
Ручной режим без окна:
    SessionCleaner.exe -console          показать список сеансов текстом
    SessionCleaner.exe -clean -yes       завершить старые сеансы
    SessionCleaner.exe -clean -dry-run   показать план, ничего не завершая

ЖУРНАЛ И НАСТРОЙКИ
Каталог данных: %ProgramData%\1C Session Cleaner
    settings.dat  зашифрованные настройки и учётные данные
    cleaner.log   журнал действий (кто и какие сеансы завершил)

ТРЕБОВАНИЯ К СЕТИ
Открыт порт 1545/TCP от компьютера администратора до сервера 1С
(служба ras.exe). Если служба администрирования остановлена, запустить её
можно прямо из настроек программы (раздел 5).
